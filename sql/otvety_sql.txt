Часть 2
1. База данных это место где хранятся данные приложения. Она нужна чтобы данные не терялись и с ними было удобно работать.
2. Таблица это общая структура. Строка это одна запись (например один пользователь), а столбец это одно поле этой записи (например имя или email).
3. Primary Key это уникальный id записи. Он важен потому что по нему можно точно найти нужную строку без путаницы.
4. Foreign Key это ссылка на id из другой таблицы. Он нужен чтобы связывать таблицы между собой.
5. One-to-many это когда у одного объекта много других. Например один пользователь может иметь много заказов.
6. Many-to-many это когда у обеих сторон может быть много связей. Например студент учится на многих курсах и на одном курсе много студентов.
7. ERD-диаграмма это схема базы данных. На ней видно таблицы, поля и связи между таблицами.
8. Индексы нужны чтобы быстрее искать и фильтровать данные. Особенно полезно на больших таблицах.
9. SQL чаще работает с таблицами и строгой схемой. NoSQL более гибкий по структуре и часто хранит данные в документах.
10. MongoDB удобнее когда структура данных часто меняется или данные вложенные. Еще удобно когда нужно быстро стартовать без жесткой схемы.
