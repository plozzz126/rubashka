Часть 2
1. React это библиотека для интерфейса. С ней сайт делают из кусочков и удобно обновляют экран.
2. Компонент это часть страницы, его можно использовать много раз. HTML-страница обычно цельная и статичная.
3. Props это данные от родителя к ребенку. Нужны чтобы передавать значения в компонент.
4. State это данные внутри компонента, которые меняются. Нужен когда что-то на странице должно обновляться.
5. Props приходят снаружи, state хранится внутри. Props обычно не меняют в самом компоненте, state можно менять.
6. useEffect нужен для действий после рендера: запросы, подписки, таймеры и очистка.
7. key нужен чтобы React понимал какой элемент в списке изменился.
8. Controlled input это когда input связан со state. Например форма входа: логин и пароль хранятся в state.
9. React Router делает переходы между страницами в React приложении без перезагрузки.
10. Деплой на Vercel: запушить проект в GitHub, подключить репозиторий в Vercel, нажать Deploy и дождаться деплоя.
