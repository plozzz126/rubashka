# Mini Products App

Небольшое React-приложение с товарами.

## Что реализовано

- Header с навигацией: Главная, Товары, О проекте
- Маршруты: `/`, `/products`, `/about`
- Отдельный компонент `ProductCard`
- Массив из 6 товаров
- Поиск товара по названию через `useState`
- Вывод списка через `map` и `key`
- Базовые стили на CSS

## Локальный запуск

```bash
npm install
npm run dev
```

## Деплой на Vercel

1. Загрузить проект в GitHub.
2. Зайти в Vercel и нажать **Add New Project**.
3. Подключить GitHub-репозиторий с этим проектом.
4. Нажать **Deploy**.
5. После сборки получить публичную ссылку.
