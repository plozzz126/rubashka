Часть 2
1. ООП в Java это подход, где код строится вокруг объектов. Он нужен чтобы проект было проще поддерживать, расширять и переиспользовать.
2. Класс это шаблон, объект это экземпляр класса. Например класс User, а объект это конкретный пользователь с именем и email.
3. Инкапсуляция это когда внутренние данные прячем внутри класса и работаем с ними через методы.
4. Интерфейс это контракт: какие методы должны быть. Абстрактный класс это база, где может быть и общая логика, и поля.
5. SOLID это набор принципов для чистой архитектуры. Он нужен чтобы код был понятнее и легче менять без поломок.
6. SRP значит у класса должна быть одна ответственность. То есть один класс — одна задача.
7. ArrayList нужен для списка, HashMap для пар ключ-значение, HashSet для уникальных элементов без повторов.
8. Java читает и пишет файлы через Scanner/BufferedReader и FileWriter/BufferedWriter.
9. JDBC это способ Java работать с SQL-базой. Обычно через DriverManager получают Connection и делают SQL-запросы.
10. Разделение на model/repository/service/main нужно для порядка. Так код проще читать, тестировать и развивать.
