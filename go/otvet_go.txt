Часть 2
1. Struct в Go это пользовательский тип, где объединяют поля в одну сущность. Например User с Name и Email.
2. Массив в Go фиксированного размера, а slice динамический и может расти.
3. Map это коллекция ключ-значение. Удобно хранить настройки, словари, счетчики, быстрый поиск по ключу.
4. В Go нет классов, но есть struct + методы + интерфейсы. Это и есть стиль ООП в Go.
5. Gin это веб-фреймворк на Go для API. С ним быстрее делать роуты, middleware и обработку запросов.
6. REST API это подход, где клиент и сервер общаются через HTTP-методы (GET, POST, PUT, DELETE).
7. JWT это токен с данными пользователя. Нужен для авторизации без хранения сессии на сервере.
8. Middleware в Gin это промежуточная функция между запросом и обработчиком. Часто для auth, логов, проверок.
9. Архитектура проекта нужна для порядка: чтобы код было легче читать, тестировать и расширять.
10. Backend делает SQL-запросы к базе (SELECT, INSERT, UPDATE, DELETE), получает данные и отдает их клиенту через API.
